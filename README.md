# Biblioteca ePub

El catálogo completo de EpubLibre en tu escritorio: buscá, filtrá, marcá leídos y pendientes, descargá por torrent y llevá tus propios ePubs. Gratis, sin instalación (se descomprime y listo), y se actualiza sola.

## Descargas

En [Releases](https://github.com/thurston73/biblioteca_epub/releases/latest), elegí el zip de tu sistema:

| Sistema | Archivo |
|---|---|
| Windows 10 / 11 (64 bits) | `biblioteca_epub-win64.zip` |
| Windows 7 SP1, 8 y 10/11 de 32 bits | `biblioteca_epub-win7-x86.zip` |
| Linux moderno (Ubuntu 22.04+, Mint 21+, Debian 12+, Fedora 36+; 64 bits) | `biblioteca_epub-linux.zip` |
| Linux más viejo (Debian 8 a 11, Ubuntu 14.04 a 20.04, CentOS 7; 64 bits) | `biblioteca_epub-linux-legacy.zip` |
| macOS | en preparación |

Descomprimí el zip en una carpeta tuya (Documentos, Escritorio) y ejecutá `biblioteca_epub` (`biblioteca_epub.exe` en Windows). Todo lo tuyo queda en la carpeta `datos/`, al lado del programa.

El manual está dentro del programa: Ayuda → Uso. Si algo falla, el registro queda en `datos/biblioteca_epub.log`.
